# Oword — DOCX 문서 편집기

Microsoft Word 문서(.docx)를 열고, 편집하고, 저장하는 오픈 소스 편집기입니다.
[Opptx](https://github.com/moonlightpark/Open-Power-Point-Editor)(PPTX 편집기)와 같은 구조로 만들었습니다. 이 구조는 [HOP](https://github.com/golbin/hop)(HWP 편집기)을 참고한 것입니다.
**문서 엔진, 렌더러, 명령 기반 UI, 데스크톱 셸**의 네 층으로 되어 있습니다. 설계는 [docs/architecture.md](docs/architecture.md)에 있습니다.

## 설치

[Releases](https://github.com/moonlightpark/Open-word/releases)에서 운영체제에 맞는 파일을 받습니다.

| 운영체제 | 파일 | 참고 |
|---|---|---|
| Windows 10/11 (x64) | `Oword_x.y.z_x64-setup.exe` 또는 `.msi` | 서명하지 않은 빌드입니다. SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누릅니다. WebView2가 없으면 설치 중에 자동으로 받습니다. |
| macOS (Apple Silicon) | `Oword_x.y.z_aarch64.dmg` | 임시 서명(ad-hoc)이라 처음 실행할 때 앱을 **우클릭 → 열기**로 실행합니다. |
| macOS (Intel) | `Oword_x.y.z_x64.dmg` | 위와 같습니다. |
| Linux (x64) | `.AppImage`, `.deb`, `.rpm` | WebKitGTK 4.1이 필요합니다(Ubuntu 22.04 이상, Fedora 36 이상 등). AppImage는 `chmod +x` 후 실행합니다. |

릴리즈 빌드는 `v*` 태그를 푸시하면 GitHub Actions([`.github/workflows/release.yml`](.github/workflows/release.yml))가 자동으로 만듭니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:5175 (샘플: /?file=./features.docx)
npm run build        # dist/ 웹 빌드

npx tauri dev        # 데스크톱 앱(Tauri 2) 개발 실행
npx tauri build      # 설치 파일 만들기
```

샘플 문서와 빈 문서는 `python3 scripts/make-fixtures.py`(python-docx 필요)로 다시 만들 수 있습니다.

## 화면 구성

Mac용 Word(Word.app)와 같은 구성입니다.

- **메뉴 막대**: 파일 · 편집 · 보기 · 삽입 · 서식 · 도구 · 표 · 도움말 (하위 메뉴 포함, macOS에서는 단축키를 ⌘ ⇧ ⌥로 표시)
- **리본**: 빠른 실행 도구 모음(저장 · 실행 취소 · 다시 실행 · 인쇄)과 탭
  - **홈**: 클립보드 · 글꼴 · 단락 · 스타일 갤러리 · 편집(찾기/바꾸기)
  - **삽입**: 페이지 나누기 · 표 · 그림 · 링크 · 날짜 및 시간 · 기호
  - **레이아웃**: 여백 · 용지 방향 · 크기 · 나누기, 단락 들여쓰기/간격
  - **검토**: 단어 개수 · 변경 내용 모두 적용/거부
  - **보기**: 인쇄 모양 · 눈금자 · 탐색 창 · 편집 기호 · 표 눈금선 · 확대/축소
  - **표 레이아웃**: 표 안에 커서가 있을 때만 나타남 — 행/열 삽입·삭제, 셀 맞춤(3×3)
  - 탭을 두 번 누르거나 ⌃ 단추로 리본을 접고 폅니다.
- **상태 표시줄**: 페이지, 단어/글자 수, 편집 기호, 확대/축소 슬라이더

## 기능

- **열기/저장**: .docx 열기(대화상자, 끌어다 놓기), 저장, 다른 이름으로 저장, 인쇄/PDF
  - 손대지 않은 문단, 표, 그림, 필드, 책갈피, 각주, 메모, 변경 내용, 머리글/바닥글, 그 밖의 XML 파트는 그대로 보존됩니다.
- **렌더링**
  - 스타일 상속(문서 기본값 → 표 스타일 → 단락 스타일 → 문자 스타일 → 직접 서식), 테마 글꼴과 색
  - 글자: 글꼴(한글/영어 따로), 크기, 굵게, 기울임꼴, 밑줄(종류별), 취소선/이중 취소선, 위/아래 첨자, 글꼴 색, 텍스트 강조 색, 음영, 대문자/작은 대문자, 숨김
  - 단락: 맞춤, 들여쓰기/내어쓰기, 단락 앞·뒤 간격, 줄 간격(배수/최소/고정), 테두리, 음영, 탭
  - 목록: 글머리 기호와 번호(1. 가. ① i. ㄱ. 일. 등 여러 형식, 9수준, 다시 시작)
  - 표: 셀 병합(가로/세로), 중첩 표, 테두리(표 스타일 포함), 셀 음영·여백·세로 맞춤, 여러 페이지에 걸친 표를 행 단위로 나누기
  - 그림(인라인/텍스트 배치), 글상자, 기호 글꼴(Symbol, Wingdings), 수식, 각주 번호, 하이퍼링크, 필드(목차, 페이지 번호), 변경 내용(삽입/삭제 표시), 메모 표시, 콘텐츠 컨트롤
  - **인쇄 모양**: 용지 크기와 여백대로 페이지를 나누고, 페이지마다 머리글과 바닥글(첫 페이지 · 홀수/짝수 페이지 구분)과 페이지 번호를 그립니다. 제목은 다음 단락과 같은 페이지에 둡니다.
- **편집**
  - 글자 입력(한글 IME 포함), Enter로 단락 나누기(제목 다음은 표준 스타일, 빈 목록 항목에서 목록 끝내기), Shift+Enter 줄 바꿈, Tab(탭 · 목록 수준 · 다음 셀)
  - 글꼴 대화상자(⌘D), 단락 대화상자(⌥⌘M), 대/소문자 바꾸기, 서식 지우기
  - 커서만 있을 때 글자 서식을 바꾸면 Word처럼 단어 전체 또는 다음 입력에 적용
  - 스타일 갤러리(표준, 간격 없음, 제목, 제목 1–3 등), 글머리 기호/번호 매기기, 들여쓰기 늘리기/줄이기
  - 삽입: 표, 그림(파일, 붙여넣기, 끌어다 놓기), 페이지 나누기, 줄 바꿈, 하이퍼링크(⌘K, 웹 주소 · 문서 안 책갈피), 날짜 및 시간, 기호
  - 그림 크기 조절(모서리 끌기)
  - **표**: 테두리선을 끌어서 열 너비·행 높이 조절, 행/열 삽입·삭제, 셀 맞춤(위쪽/가운데/아래쪽 × 왼쪽/가운데/오른쪽)
  - 페이지 설정(용지 · 방향 · 여백, 여백 미리 설정)
  - 변경 내용 모두 적용/거부
  - 복사/붙여넣기(문서 안에서는 서식 유지, 텍스트만 붙여넣기), 찾기/바꾸기, 실행 취소/다시 실행(300단계)

## 테스트

```bash
npm test                                  # 엔진 테스트 39개 (vitest + jsdom)
npm run dev  →  http://localhost:5175/?selftest   # 브라우저 셀프 테스트 44단계
```

- `tests/fixtures/features.docx`는 13쪽짜리 기능 점검 문서입니다(`python3 scripts/make-features.py`로 생성). 표지, 목차 필드, 글자/단락 모양, 다단계 목록, 병합·중첩·긴 표, 떠 있는 그림, 글상자, 수식, 각주, 하이퍼링크, 변경 내용, 메모, 콘텐츠 컨트롤, 구역 나누기, 첫 페이지/짝수·홀수 머리글이 들어 있습니다.
- 셀프 테스트는 개발 서버에서만 동작하며, 실제 브라우저에서 입력 이벤트로 편집기를 조작해 입력 · 서식 · 메뉴 · 리본 · 표 테두리 끌기 · 그림 · 붙여넣기 · 실행 취소 · 페이지 배치 · 인쇄 배치 · 저장 후 다시 열기를 확인합니다. 결과는 화면과 `tests/out/selftest.json`에 남습니다.

## 구조

```
src/engine/          문서 엔진 (UI 의존성 없음)
  package.ts         OPC 컨테이너: zip, 관계, 콘텐츠 형식, undo용 스냅샷
  document.ts        DocxDocument: 문단/표/그림/목록/쪽 설정 명령 + 트랜잭션 undo
  model.ts           문단 내용 모델(항목과 길이), 런 나누기/합치기, 속성 쓰기(스키마 순서 유지)
  styles.ts          스타일·테마 상속 계산
  numbering.ts       목록 정의와 번호 매기기
  render.ts          문서 → 편집 가능한 HTML 렌더러 (1pt = 20 twip = 12700 EMU)
  edit.ts            DOM 위치 ↔ 모델 위치, 편집한 DOM → w:p 반영
src/ui/              편집기 UI (HOP · Opptx와 같은 메뉴/툴바/서식 바/눈금자/상태바)
  editor.ts          contenteditable 편집기, 쪽 나누기 배치, 선택 영역 복원
src-tauri/           데스크톱 셸 (네이티브 파일 대화상자, 임시 파일 후 rename 방식 저장)
tests/               엔진 테스트 + 샘플 문서
```

## 제약

- 페이지는 단락(표는 행) 단위로 나눕니다. 한 페이지보다 긴 단락이나 행은 페이지 경계를 넘어 그려질 수 있습니다.
- 사용자 지정 탭 위치(오른쪽 탭, 채움선 등)는 기본 탭 간격으로 보입니다.
- 떠 있는 그림은 왼쪽/오른쪽 배치와 위아래 배치만 반영합니다(정확한 위치 값은 보존됨).
- 차트, SmartArt, EMF/WMF 그림은 자리 표시 상자로 보입니다(보존됨).
- 각주/미주 본문과 메모 내용은 본문에 펼쳐 보이지 않습니다(메모는 표시 위에 마우스를 올리면 보임, 보존됨). 머리글/바닥글은 읽기 전용입니다.
- 셀 병합/분할, 변경 내용 추적 기록은 아직 지원하지 않습니다.
- 줄바꿈은 브라우저 레이아웃을 쓰기 때문에 Word와 약간 다를 수 있습니다.
